# 阶段 4 行走验收

入口通过角色的 `submit_intent` 提交世界空间目标速度和朝向，从 `get_state` 取得全身实测状态，从 `get_gait_telemetry` 取得控制器声明的阶段、支撑脚、换撑计数和地面探测。原生流形探针独立量测受载足底材料点相对固定地面的滑动。测试中唯一的外部输入是行动意图。

## 工况与预设判据

每个工况启动独立 Godot 进程、GodotPhysics3D 空间、128 次求解迭代与固定 60 Hz。总时长 15 秒，共 900 个连续物理步，含无输入稳定 2 秒、持续驱动 10 秒、松开 3 秒。所有姿态失败都会保留至时窗末尾。

| 工况 | 速度及朝向 |
|---|---|
| 前进、后退、左横移、右横移 | 保持面朝 −Z，分别沿目标方向要求 0.80 m/s。 |
| 左转、右转 | 要求前进 4 秒，随后在世界空间左转或右转 90°，沿新方向继续 6 秒。输入朝向与行进方向一起旋转。 |
| 慢走 | 前进 0.35 m/s。 |
| 不规则地面 | 前进 0.80 m/s。出生前方 0.75 m 处起为实际连续坡面，每段长 0.5 m，节点相对高度依次为 0、22、9、34、15、0 mm，然后循环。 |

| 观测 | 通过条件 |
|---|---|
| 完整性、姿态 | 全部 900 帧时钟连续，全身 COM 与骨盆相对脚下地面高度始终 ≥0.65 m，胸部倾角 ≤35°，无跌倒或非足支撑。 |
| 实际位移、速度 | 每直线段沿目标方向的净位移 ≥指令积分的 60%，任一帧对该段起点直线的横向偏差 ≤0.30 m。去掉每段最初 1 秒后，质量加权 COM 平均顺向速度须为目标的 60%–140%，水平速度向量 RMS 误差 ≤0.45 m/s，慢走 ≤0.25 m/s。 |
| 朝向与停止 | 同一稳态窗口内实际胸部朝向误差 RMS ≤30°。停止后最后 1 秒的 COM 水平位移峰值 ≤0.12 m，水平速度 RMS ≤0.15 m/s，实际胸部朝向误差峰值 ≤30°。 |
| 足底支撑 | 驱动期间最长连续低载荷或双脚离地 ≤0.10 s，低载荷阈值为体重的 2%。合计的实测足底竖直反作用冲量/体重冲量须在 0.85–1.15 之间。每脚受载材料点切向滑速 RMS ≤0.12 m/s。 |
| 声明与真实换撑 | 驱动期间至少有 4 次支撑切换。每次计数增 1，新支撑与上一帧不同，新脚有真实支撑且瞬时承重 ≥15% 体重。 |
| 实际踏步 | 每脚至少完成 2 步，实测左右落脚间至少交替 3 次。一次踏步要求先有承重，随后至少 2 帧离地或承重小于体重的 5%。卸载期间须有一帧脱离鞋底接触流形，鞋底标记相对地面升高 ≥0.015 m，脚与离地前的水平位移 ≥0.07 m，慢走 ≥0.04 m，再次承重 ≥15%，且落脚时躯干仍直立。 |
| 环境探测 | 有地面探测时要与已知地形高度相符（误差 ≤0.015 m），法向相对实际坡面的误差 ≤1°，拼缝处允许任一相邻面的法向。不规则地面工况要求探到 ≥1° 的坡面，且多次实际踏步的落脚地面高差 ≥0.012 m。 |

原生足底材料点速度采用与站立夹具相同的逐步姿态差分，并按原生接触竖直冲量加权。事件表保留低载荷后的重新受载、符合完整踏步判据的真实落脚，以及控制器声明的换撑。直立和承重是两个独立门槛，倒下后身体接触地面仍会计入失败帧。

站立基线探针使用本步原生脚掌姿态筛选鞋底带内触点，随后使用前后两步姿态求材料点切向位移。卸力复测版行走控制器使用上一步脚掌姿态判断接触见证点是否属于鞋底。脚部快速翻转时两种筛选可能取得不同的触点集合，CSV 分别保留原生探针与控制器状态的足底冲量。安全卸力一经触发，独立行走夹具将 `walking_actuation_released` 记为失败。任一物理步任一关节锚点分离严格大于 0.20 m 时另记 `anchor_separation_over_20cm`。同一帧有多个关节超限，汇总的 `anchor_over_20cm_frames` 只加一。

摘要分别列出跌倒标志从无到有的次数与跌倒持续帧数。调试轨迹会逐帧记录六个腿段的姿态、角速度、髋膝踝力矩占上限的比例、锚点分离，以及关节两侧原始局部 Z 轴夹角。该夹角用于辨认膝铰链的轴线对齐程度；髋踝可多轴旋转，局部 Z 轴夹角随主动姿态变化。

## 复测

```powershell
godot --headless --fixed-fps 60 --path . --script res://game/actors/physics_character/active_tests/verify_walking.gd -- --case=forward --out=C:/Temp/walk-forward --trace
python game/actors/physics_character/active_tests/run_walking.py --godot C:/Godot/Godot_console.exe --out C:/Temp/walk-all --jobs 3 --trace
```

逐案输出摘要 JSON、支撑/落脚事件 CSV，加入 `--trace` 可导出 900 帧速度、朝向、足底轨迹、载荷、滑移、目标足位及探测数据。完整矩阵汇总到 `walking_body.csv` 和 `walking_events.csv`。退出码 0 表示物理判据全部通过，1 表示至少一项物理验收失败，2 表示夹具、引擎或文件出错。
