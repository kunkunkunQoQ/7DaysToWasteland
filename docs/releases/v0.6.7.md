# 七日荒原 0.6.7 · 地形图鉴与荒原光影

打开主菜单的「荒原图鉴 → 地形」，可以从山脚看到霜脊雪山的峰顶，沿红岩峡谷看两岸与河床，也能俯瞰沙漠绿洲的完整岸线。

## 地形与光影

- 18 种地形都从游戏世界独立取景，按实际地势展示坡面、土层、植被和水深。拖动鼠标或单指滑动即可旋转，也可以用按钮转向、切换俯视与斜视。预览下方标明取样范围。
- 晨昏的阴影平滑转向，夜里更容易辨认建筑和地面。普通月光在水面留下冷色倒影，血月时转红。云影随日照变化，提灯照亮的地面和阴影里的墙面裂纹也能正确显示。

## 物资与联机

- 在「探索手记 → 获取方式」中可搜索 136 种物品的来源。也可以从背包或制作配方的原料直接跳转，查完再回到原处。地上静止的同类散料在近距离会合堆，手动拾取时会显示拿到的数量和留下的余量。
- 每位玩家拥有独立的背包、装备、快捷栏和随身制作队列。箱柜与世界进度仍由队伍共享。队友可以在暂停菜单选择「保存世界」，下次从原设备重连后接着使用自己的背包。

## 安装与升级

- **联机前请所有人一同升级至 0.6.7。** 本次更新了局域网协议。升级旧世界时，原共享物资和随身制作队列归房主。
- **Windows x64** 下载 `7DaysToWasteland-Windows-x64.zip`，解压后运行 `7DaysToWasteland.exe`。如需 OpenGL 兼容模式，运行同目录的 `Start-Compatibility.cmd`。
- **Android** 下载 `7DaysToWasteland.apk`，可直接覆盖安装 0.6.6 正式版。此前单独安装的图鉴测试版保有自己的存档，正式版继续使用正式存档。
