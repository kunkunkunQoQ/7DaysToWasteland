# 七日荒原 0.6.6 · 六人局域网协作

本版本将局域网房间从双人扩展到 **最多 6 人（1 位房主 + 5 位队友）**。

## 联机更新

- 「附近的世界」显示真实的 1/6 至 6/6 房间人数，满员无法加入。
- 五位队友分别同步角色外观、昵称、位置、动作、灯光、主手快捷格、副手、生命与伤病。队友加入、退出、换装和改名都会同步给其他玩家。
- 共享背包支持多名玩家各自预留副手物品。所有玩家都可查看同一个箱子并存取物品，不会因同时取物而复制库存。
- 生物感知、区域伤害、倒树碰撞、探索、车辆、掉落物和中继守听均支持整支队伍。
- 角色倒地、复苏及断线重连按玩家分别处理，房主存档继续保留每位队友的状态。

## 使用方法

在同一局域网中，房主从单人存档的暂停菜单开放世界；其他玩家选择「局域网协作 → 附近的世界」，也可手动输入房主的局域网 IP 和端口。队伍继续共享物资和世界进度，并维持原有的房主附近活动规则。

**联机各方都需要使用 0.6.6，不能和旧的双人协议混连。** 原有的单人世界及队友存档可以继续使用。

Windows x64 下载 ZIP 后解压运行，Android 下载 APK 后安装（覆盖更新时保留原来的应用身份）。

## 验证

六人 ENet 回环测试 136 项、原双人联机回归 206 项、相关单机回归 221 项均通过。Windows 和 Android 发行包均进行资源与联机检查；Android APK 保留上一版的签名。尚未进行 Android 真机及六台实际设备的局域网压力测试。
